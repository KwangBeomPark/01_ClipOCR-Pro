여섯 앱에 동일한 Windows PowerShell 백업/검증/새 폴더 복원 도구와 앱별 자료 범위를 제공했습니다. 기본 백업은 UserSetting 전체이며, 04 datasets·06 results 제외는 명시적인 SettingsOnly 옵션입니다. 외부 업무 파일은 자동 탐색하지 않습니다. 실행 중 앱·잠긴 파일·링크·ZIP 경로 탈출·중복/손상/다른 앱 백업을 거부합니다. 기존 활성 폴더를 자동 덮어쓰지 않습니다. [사용자 자료 계약](USER_DATA.md)을 따릅니다.

공개 저장소의 UserSetting·환경 파일·개인 키 제외, 중립 SMTP fixture, 개인 서명 도구 경로 제거, 모든 앱의 공개 CODE_MAP/README 연결을 적용했습니다. 제품 이름·버전·AppId·설치 폴더·기존 단축키는 유지합니다. 04의 기존 미커밋 구조 메모는 원문을 보존하고 현재 역할 기준을 별도로 명시했습니다.

배포 소스는 앱/런처 서명 → ZIP/설치 생성 → 설치 파일 단일 서명 → 별칭 복사 → 해시/서명/매니페스트 검증 → 공식 폴더 반영 순서입니다. 실패 결과를 공식 파일로 승격하지 않으며 기존 게시 태그/자산을 덮어쓰지 않습니다. 기존 배포물을 재서명하지 않았습니다.

Python 합계 **1,090개 실행: 1,088개 통과·2개 제외, 별도 36 subtests 통과**. 제외 항목은 선택적 Excel COM과 보안 정책에 막힌 미서명 설치 정책 실행입니다. 백업 합계 **196 assertions**, 배포/도구/명시 서명 게이트 **184 assertions**로 PowerShell 합계 **380 assertions**입니다. 모의 서명 성공은 실제 인증서 서명으로 집계하지 않습니다.

추가로 여섯 저장소 PowerShell 56개 파일 파싱, 변경 Python lint/구문 검사, git diff --check를 확인했습니다. 06/07 canonical·호환 설치 정의 4개는 실제 Inno Setup 6으로 격리 더미 페이로드를 컴파일했습니다. 01/02는 2단계에서 실제 미서명 AHK/ZIP/Inno 빌드를 확인했습니다.

총괄은 이동한 **05 installer/App05_FileOps.spec 및 07 installer/eml_viewer.spec로 실제 전체 PyInstaller 미서명 빌드**를 수행했습니다. 둘 모두 exitCode=0, sourceStable=true이며 officialPromoted=false입니다. 최신 소스 빌드 증거는 각 build/standardization/canonical-package-result.json 및 해당 소유 빌드 폴더에 있습니다. 설치 실행·서명 성공을 의미하지 않습니다.

원본 보존·쓰기/flush/교체 실패·암호화 실패·메모리 상태·반복 이관·동시 target 생성·구형 백업·복원 rollback 실패·ZIP 위조/범위·경로·프로세스 잠금 등을 검사했습니다. 교차 검수로 발견한 02 복구 사본 삭제 위험, 04 손상 정의/최근 작업 보호, 05 실패 성공 표시, 06 결과 경로 누락, 07 부분 이관 노출은 수정 후 회귀로 확인했습니다.

설치는 **정상 종료 요청/종료 안내 → 잠금 차단 → 새 파일 반영 → 성공·소유권·해시 확인 후 구형 EXE만 정리**하는 정책입니다. 구버전 폴더 전체를 먼저 지우지 않습니다. 07의 기존 AppMutex는 사용자가 닫도록 안내/차단하며 자동 종료 확인으로 표시하지 않습니다. 실제 설치 합격 기록 없이 이 정책의 실환경 성공을 단정하지 않습니다.

현재 PC에는 Windows Sandbox 실행기가 없고 미서명 QA 실행은 Windows Application Control에 차단된 전력이 있습니다. 정책을 해제하거나 우회하지 않았습니다. 06 기본 Windows Qt 플러그인의 테스트 종료 충돌 때문에 자동 회귀는 offscreen을 사용하며, 실제 UI·DPI·포커스·단축키 시험은 남깁니다. 실제 업무 화면, SMTP/번역/외부 서비스, 동일 사용자 DPAPI 복원도 별도 게이트입니다.

## 보호 및 재개 자료

새 서명·게시·버전 변경·커밋/push·실제 설치/제거를 수행하지 않았습니다. 각 담당은 이번 3~5단계의 APPDATA/LOCALAPPDATA/USERPROFILE 등 필요한 테스트 경로를 격리했습니다. 2단계 초기에 05 실제 진단 로그에 기록이 추가된 사실과 당시 임시 정리 거부는 [이전 단계 기록](STANDARDIZATION_PHASE2_SUMMARY.md)에 보존합니다.

07 installer에 남아 있던 과거 배포 관련 파일 16개는 이동 전후 해시를 검증해 Git 제외 build/release-history/installer-legacy-32132f70113a45c09383faac9327362a에 보존했습니다. preserved-files.json에 원래 경로·크기·해시가 있습니다. 공식 release/ 파일 및 현재 설치는 그대로입니다. 공통 검수 fixture도 삭제하지 않고 Git 제외 build에 유지합니다.
